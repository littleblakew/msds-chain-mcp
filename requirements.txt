# CI-242: ported to mcp 2.x (was pinned `>=1.0.0,<2` after mcp 2.0.0 removed
# `mcp.server.fastmcp`, which server.py was built on). The 2.x floor is NOT cosmetic —
# 1.x tops out at protocol 2025-11-25 and has no `server/discover` / `resultType` /
# `ttlMs`, i.e. the 2026-07-28 spec work (CI-515) cannot be built on it. Keep the <3
# ceiling: an unpinned major is exactly what broke the v1.5.3 release (clean-env
# resolver picked up a major that had removed our entry point, while the self-hosted
# runner's cached install masked it and CI went green).
mcp>=2.0.0,<3
httpx>=0.27.0
uvicorn>=0.30.0

# `_streamable_app.router.routes` 和 `router.lifespan_context`——**不是稳定公开 API**。
# mcp 只要求 `starlette>=0.27`，所以干净解析器现在就会装到 **1.6.0**（不是这次改的，

starlette>=0.38.0,<2
